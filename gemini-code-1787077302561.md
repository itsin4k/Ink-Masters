# Ink Masters Studio - Sitio Web Oficial

Proyecto web responsive e interactivo para **Ink Masters Studio**, estudio de tatuajes y perforaciones en Cancún.

## 📌 Características
- Menú de navegación adaptativo y responsivo para dispositivos móviles.
- Sección de servicios y estilos de tatuajes.
- Galería/Portafolio dinámico con enlaces de alta calidad.
- Tabla de precios informativos.
- Formulario para agenda de citas con validación de fechas futuras.
- Sección de contacto con enlace directo a Google Maps (Plaza Las Américas, Cancún).
- Sistema interactivo de comentarios y calificaciones en vivo.
